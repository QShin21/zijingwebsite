## 服务端增量

`src/app/(frontend)/api/miniapp/[...path]/route.ts` 增加以下 JSON 入口：

- `GET status`：接口能力信息。
- `POST auth/login`：邮箱或昵称登录，仅返回当前用户最小信息及 Payload 会话。
- `POST auth/register/begin`、`auth/register/complete`：复用网站邮箱验证码注册动作，不接受客户端角色或系统上下文。
- `POST auth/password/code`、`auth/password/reset`：沿用清华邮箱白名单、验证码尝试限制与受控密码修改。
- `GET reactions`、`POST reactions/toggle`：只操作当前用户互动，对象公开读取显式 `overrideAccess:false`、匿名、最小字段。

互动写操作要求显式 JWT / Bearer 凭据；浏览器 Cookie 无法单独授权互动。登录与邮箱验证接口沿用网站现有校验规则。新接口无需数据库迁移。网站尚未更新这些接口时，客户端可使用完整邮箱通过既有 REST 接口登录；昵称、原生邮箱验证及点赞切换需要启用桥接接口。

## 本机预览与上传

微信开发者工具导入 `miniprogram` 目录，使用上述 AppID。已登录账号需要具有该小程序开发权限。命令行使用工具设置中的服务端口，访问令牌仅通过当前进程环境变量 `WECHAT_DEVTOOLS_CLI_TOKEN` 读取；不得填入项目配置、Git 或验收记录。

```powershell
# WECHAT_DEVTOOLS_CLI_TOKEN 由本机安全环境提供
$env:WECHAT_DEVTOOLS_PORT = '<开发者工具服务端口>'
pnpm miniapp:check
pnpm miniapp:preview
pnpm miniapp:upload
```

如工具安装位置不同，设置 `WECHAT_DEVTOOLS_PATH` 为安装目录。脚本适配本机 Windows 工具的路径大小写问题，复用现有配置目录；连接仍经过开发者工具的认证。预览二维码与上传返回信息写入被忽略的 `miniprogram/preview/`，不会提交。上传仅生成开发版本，不提交微信审核或发布正式版本。

微信公众平台中 request 与 downloadFile 合法域名需配置 `https://home.thuzijing.top`。共享工程保持 `urlCheck:true`，不通过关闭域名校验冒充联网成功。图片选择与个人资料处理还应在微信平台按实际功能填写隐私声明；实际手机授权及账号成功登录按本次执行证据单独记录。
