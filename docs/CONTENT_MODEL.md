# 内容模型

| 集合/全局   | 内容与关系                                                     | 规则                                                  |
| ----------- | -------------------------------------------------------------- | ----------------------------------------------------- |
| users       | 后台邮箱、角色数组、负责 teams                                 | 公众不可注册；角色和分部仅管理员修改                  |
| games       | 名称、slug、正文、图标/封面、排序                              | 各栏目共享分类                                        |
| teams       | 游戏、队名、封面、说明                                         | 分部负责人仅维护所属队伍草稿                          |
| seasons     | team、赛季、开始、成员昵称/位置/授权                           | 每赛季独立；公开昵称须勾选授权                        |
| honors      | team、season、game、赛事、组别、名次、日期、公开来源、verified | 发布且已核验；需 HTTPS 来源；赛季与队伍一致           |
| events      | 时间、地点、游戏、类型、生命周期、报名窗口/渠道                | 内容、活动、报名状态分离                              |
| recruitment | kind、窗口、岗位、职责、要求、投入、安排、联系                 | 三类：members / teams / staff；新轮次新记录           |
| news        | 类型、日期、event/team、正文                                   | 回顾关联活动                                          |
| albums      | event、日期、图片关系与说明                                    | 每页 12 张，最多 200 张/相册                          |
| media       | alt、credit、文件、800px卡片尺寸                               | 公开文件；上限8MB/4000万像素；拒绝SVG、HTML等主动内容 |
| pages       | key、正文、分区标题/文字                                       | about/contact/privacy/join及三类加入说明；key唯一     |
| site        | 名称、首屏、媒体/按钮、联系方式、导航、模块顺序、推荐          | 仅管理员更改；模块为受约束集合                        |
| redirects   | from/to                                                        | 改已发布slug时自动记录；站内详情跳转                  |
| audit       | 时间、操作者ID、操作、对象、状态                               | 只读；不含密码、请求体、令牌和正文                    |

内容共同字段：title、稳定 slug、summary、body、cover、archived、demo、SEO、版本状态。`internalNotes` 为内部核验备注，匿名不可读取。关系深度默认0。

所有日期 PostgreSQL timestamptz 存储 UTC，后台/前台按上海时区显示。历史记录不被当前赛季覆盖。公开页面只渲染允许的字段，荣誉非公开证明文件不得上传公开媒体。
