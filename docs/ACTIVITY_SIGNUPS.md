# 活动报名问卷（0.2.0）

## 发布与填写

- 网页：游戏项目 → 活动与通知 → 发布活动与通知，在发布前启用并编辑报名问卷；活动详情的管理入口可再次编辑或查看名单。
- CMS：先保存活动草稿，点击“编辑报名问卷、查看报名名单”。站点编辑者保存的问卷随草稿审核发布。
- 小程序：有权限的发布者从“我的 → 活动问卷管理”选择游戏活动或站点活动，编辑已有活动（含有权限的草稿）的问卷；活动详情也提供管理入口。
- 问卷支持单行文本、多行文本、单选、多选、必填、题目排序、说明、开放/截止时间及暂停报名。每份最多 20 题。
- 成员在活动详情填写并提交，服务端校验通过即确认报名，重新打开可查看确认与原答案。重复点击或重试不会生成多份报名。
- 管理者可分页查看报名名单及答案；普通成员只能读取自己的报名。问卷修改后保留旧报名的题目和答案快照。
