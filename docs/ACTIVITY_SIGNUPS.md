# 活动报名问卷（0.2.0）

## 发布与填写

- 网页：游戏项目 → 活动与通知 → 发布活动与通知，在发布前启用并编辑报名问卷；活动详情的管理入口可再次编辑或查看名单。
- CMS：先保存活动草稿，点击“编辑报名问卷、查看报名名单”。站点编辑者保存的问卷随草稿审核发布。
- 小程序：有权限的发布者从“我的 → 活动问卷管理”选择游戏活动或站点活动，编辑已有活动（含有权限的草稿）的问卷；活动详情也提供管理入口。
- 问卷支持单行文本、多行文本、单选、多选、必填、题目排序、说明、开放/截止时间及暂停报名。每份最多 20 题。
- 成员在活动详情填写并提交，服务端校验通过即确认报名，重新打开可查看确认与原答案。重复点击或重试不会生成多份报名。
- 管理者可分页查看报名名单及答案；普通成员只能读取自己的报名。问卷修改后保留旧报名的题目和答案快照。

## 2026-10-11 网页问卷增强

参考问卷星公开帮助中的[题目关联与跳题说明](https://www.wjx.cn/Help/Help.aspx?helpid=218)及[常用题型、编辑操作](https://www.wjx.cn/help/help.aspx)，按活动报名场景实现以下能力：

- 填写：分页（默认每页 5 题）、填写进度、必填标记、题目提示、占位提示、字数计数、逐题错误及焦点定位、上一步保留答案、提交前核对、失败保留内容并可重试。填写内容保留于当前页面内存，刷新或关闭页面后需重新填写。
- 校验：单行/多行文本可设字数上下限、邮箱、11 位中国大陆手机号或数字格式；多选可设最少/最多数量，以及一个互斥选项（例如“均不参加”）。选填题可留空；互斥项允许单独提交，不受最少选择数限制。
- 条件显示：关联前面的单选或多选题中的一个选项。前置题本身隐藏时，后续关联题也隐藏。切换分支会清除隐藏答案；服务端独立判断可见题目，忽略伪造的隐藏答案，并只保存可见题目快照。允许多级关联；禁止循环、向后引用及无效选项。
- 编辑：每页题数、复制题目、折叠高级设置、交互式填写预览。预览使用实际填写组件及同一校验规则，不创建报名。删除被关联的题目会先确认，再将直接关联题改为始终显示；改动顺序或选项造成无效关联时，预览及保存均拒绝并提示修正。

入口保持不变：活动详情 → 编辑报名问卷 / 查看报名名单。展开某题的“填写提示、校验与显示条件”可配置高级功能；保存前可点击“预览填写效果”。发布活动时的问卷编辑器和 CMS 跳转管理入口共享这些能力。

兼容与范围：保留四种原有题型、20 题上限和原答案格式；未配置新属性的旧问卷规范化结果与版本摘要输入保持不变。采用现有 JSON 字段，无新增数据库迁移；旧答卷快照保留。权限、草稿审核、账号去重和时间窗口沿用已有服务端检查。本轮仅更新网页交互和共用服务端规则，小程序 0.2.0 仍使用原填写界面，会显示全部题目，新增条件显示、分页、提示和本地校验尚未同步；其提交仍受服务端新规则校验，隐藏答案不会入库。小程序更新须在 littleapp 分支另行实施并验证。

回滚注意：高级配置上线并产生新问卷后，旧代码会忽略高级规则。应保留当前服务端校验，或先暂停相关问卷再评估代码回退；不要删除已有报名数据。
