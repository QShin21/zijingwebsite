# AI 问卷可靠性与名单填写 · 2026-10-11

本轮修复用户测试校内赛报名问卷时的“AI 草稿未生成完整”错误，并完善由需求生成、预览、修改、编辑和实际填写的流程。

## 生成与完善

用户明确要求由提示词决定题量。因此移除制作页面题数选择、服务端固定题数和 3–30 题校验、编辑器与配置的 100 题数量门槛。题数由模型根据需求安排；用户仍可在需求中说明希望的题量。配置及请求的内容体积、超时和权限检查继续生效。

原样复现截图需求时，上游返回 `finish_reason=length`，4,600 个输出 token 全部为思考 token，正文长度为 0。依据 [DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/) 与 [JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)，调用固定模型时显式设置 `thinking.type=disabled`、JSON 输出模式及足够正文预算；这些参数已在 Paratera 实际验证。

生成最多调用两次上游，第二次用于截断、空正文、结构/逻辑错误的修复或暂时服务错误的重试。结构错误会附上具体校验原因和待修复草稿；截断则重新生成完整正文。取消、授权和限流错误不重试。一次制作及其自动修复共占一次制作额度，仍为每账号每小时 6 次、全站 60 次、同时 2 次。单次上游等待 65 秒，总等待 120 秒；响应最多 400 KB，问卷配置最多 200 KB。

编辑器默认智能判断分支，提供三类需求示例。通过 NDJSON 显示设计、检查和修复阶段及等待时长，可随时取消。连接中断且没有完整结果时拒绝应用。旧 JSON 接口仍可使用；旧请求中的题数字段被忽略。完善草稿只发送制作需求、选中的 AI 草稿及修改意见；不读取已有答卷或账号资料。请求最多 224 KB，容纳草稿和修改意见；不自动保存或发布。

## 可增减信息组

新增第 16 种题型 `group`，适用于全员名单、同行人员和重复明细。题目可设置 1–20 条记录范围，每条包含 1–10 个文本、下拉或数字字段，字段支持必填、格式、长度和数字限制；组内不支持递归信息组及分支。组题本身可按前置题条件显示，不能作为分支条件来源。

团队名单设置 `minEntries=5,maxEntries=6`，默认显示五条，最多增加一条。第六条一旦添加须完成其中所有必填字段，也可移除；服务端独立拒绝 4 人、7 人、不完整成员、伪造字段和无效选项。切换个人报名会移除隐藏的名单答案。问卷预览、编辑字段、草稿续填、提交核对、本人回执、名单快照、答案筛选、CSV 和按版本统计均支持信息组。CSV 保留每人每个字段的标签与答案。

仍使用现有 JSON 配置及答案快照，无数据库迁移。旧基础小程序遇到信息组继续收到网站填写提示；本轮没有上传小程序。
