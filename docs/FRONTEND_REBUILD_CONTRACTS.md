## 当前权限与素材决定

- 匿名网页仍限 `/events`、`/announcements`、登录、注册、密码重置及隐私；首页匿名仍跳活动，社群/队伍等仍进入登录。现有门禁与任务书的更宽浏览目标有差异，按最新集成指令维持安全源码范围。
- 骨干可审核内容升推；骨干招新管理仍只有 `canManageStaffRecruitment = canPublish` 授权的主席/副主席。社群/队伍任职独立于平台角色，不借改版扩权。
- 公开读取保持 `overrideAccess:false`、匿名身份、最小投影、非草稿；本人事务显式过滤当前本人并再次执行集合访问权限。UI不直接查询私有资料填充公共界面。
- 仓库没有可核验授权的真实校园/活动照片，默认封面采用文字和真实发布内容。CMS配置的图片保留原受控媒体入口；不使用旧生成金属主视觉作新方向，不编造影像标题、赛事成绩、人数或活跃度。
- 保留已有几何Z界面标记与“竞在紫荆 / ZIJING ESPORTS”文字；几何标记不是大学校徽或校方背书。原生20个tab图标为既有原创线条，从共同主题色重新生成。字体用系统中文回退，未新增网络字体。

## 设计系统与兼容实现

`src/design/tokens.json` 是唯一色板、字级、间距、圆角、层级、动效来源。`node scripts/build-design-tokens.mjs --native-config` 生成网页CSS、原生JS与启动JSON；`--check`验证无漂移。网页仍SSR读取 `zijing_theme`，无偏好一律浅色，切换不刷新路由；原生同名本地偏好保持生命周期/作答状态。`tests/design-tokens.test.ts`验证两套主题的普通文字4.5:1、必要控件边界/焦点3:1及生成一致性；实际页面还需Axe与人工视觉审视。

普通分隔线与输入框边界独立：浅色普通线 `#DFDDD8`，必要控件边界经真实对比计算调为 `#807A82`。公共容器1280、中文正文16/1.7、移动16–20侧距、默认小圆角6–8；布局按首页、目录、正文、表单与工作台分别组织。

原生保持真正WXML/WXSS/JS；网页DOM映射仅用于有限视觉辅助，不能当成官方小程序编译或真机验证。官方开发工具、平台基础库、微信图片菜单/键盘/安全区、iOS/Android与发布验收单列未运行。

未知写结果不自动重放；活动“刷新核对”保留当前修改及原修订号，另列服务器回执，只有本人明确重载才替换作答与版本。队伍操作需要先查看最新记录并确认未保存；荣誉新建未知时保留实际提交队伍、文件引用与再次核对要求。荣誉审核拒绝不刷新当前页面或推进版本，保留说明，成功才失效缓存；这些是前端反馈适配，原权限服务、状态机与CAS没有放宽。

## 全面设计实施后的合同补充 · 2026-10-14

- 公共 Content 读取只新增已有 `publishedAt` 字段，供公告与动态显示真实发布时间。队伍目录的 `publicTeamMeta` 仅查询已公开对象 ID 的 `teamStatus`，继续匿名、`overrideAccess:false`、`draft:false`、最小 select。没有通过前端补读私人申请、成员联系方式或未审媒体。
- 社群新增四个呈现适配器：`decideCommunityResultAction`、`handleJoinResultAction`、`updateCommunityCardResultAction`、`replaceShowcaseVideoResultAction`。仍调用原权限、事务、CAS、文件验证与业务服务；拒绝时返回反馈并保值，成功才失效缓存和导航至稳定回执。旧 action 保留兼容。
- 社群申请未知结果提供新窗口核对本人记录，原窗口输入与 File 保留，无自动重放；用户仍能手动重试，不声称新增了客户端幂等键。联系方式独立默认不勾选、精确同意文案与服务端校验不变。
- 骨干修改和问卷管理的 GET 核对只存独立服务器回执/版本，保留当前草稿和旧 CAS。只有明确选择放弃修改后重载，才替换表单或版本。`ActionForm`、`client-request`、`action-feedback` 与本轮基线内容一致。
