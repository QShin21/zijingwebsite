# 作答修改与小程序新版报名 · 2026-10-12

报名提交后，网站与小程序的本人回执新增“修改作答”。修改表单自动带入上次提交的答案，包括个人与团队分支、成员名单、矩阵和排序；用户修改、核对后再次提交。取消修改保留原答卷，网络或保存失败保留正在修改的内容，可重试。管理员名单、统计和 CSV 使用保存后的最新答案；报名编号、原报名时间及记录数量保持不变。

## 服务端与版本

- `PATCH /api/activities/{kind}/{id}/signup` 接收当前问卷 `version`、上次回执 `revision`（`updatedAt`）和完整 `answers`。要求有效登录、本人记录、活动可访问且报名仍开放；当前问卷及服务端路径和答案校验均通过后才能保存。
- 更新在 PostgreSQL serializable 事务中读写，拒绝旧回执和并发覆盖，返回 409 并提示重新加载已提交内容。原 POST 保持首次提交的幂等行为。集合 REST / CMS 更新入口继续拒绝直接修改；服务端更新上下文和本人范围均受限，不能改成员、所属活动、去重键等字段。
- 问卷更新后按当前结构带入可用答案，清理隐藏或已删除字段，提示检查新增必填题。关闭、延期、取消或报名时间结束后暂不能修改。
- 小程序声明 `X-Questionnaire-Version: 3`，网站继续兼容版本 2。缺少新版协议的旧 JWT 客户端读取扩展题型或条件问卷时收到网站填写提示。
- 无新增数据库迁移，保留既有报名及问卷 JSON 快照。当前更新覆盖本人记录中的答案及问卷快照，没有新增逐次修改历史。

## 小程序 0.3.0

在 `littleapp` 分支更新原生报名页，支持全部 16 种题型、复合显示条件、分页、优先级跳转、提前结束、核对提交、错误定位、原答案修改及失败重试。团队报名可填写五至六人成员，增加第六人后需填完必填字段，切换个人报名时清除隐藏团队答案。信息组、矩阵、排序和多项填空在回执与管理名单中完整显示。

网站 TypeScript 规则通过 `pnpm miniapp:generate` 生成小程序 CommonJS 模块。生成时补齐 UTF-8 长度及旧运行时缺少的标准库函数；`pnpm miniapp:check` 比较生成内容与源文件，避免两端规则漂移。开发者工具工程保持 `urlCheck:true`。高级问卷管理显示完整结构与网站编辑入口，避免基础原生编辑器丢失高级配置。
