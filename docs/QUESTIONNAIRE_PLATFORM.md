## 当前可用

| 环节 | 能力 | 实施边界 |
| --- | --- | --- |
| 入口 | 账号页问卷工作台；活动详情管理；独立填写链接及复制 | 沿用站点活动和社群活动作为问卷载体，填写需要登录 |
| 创建 | 空白编辑、8 类完整模板、AI 制作、批量文本导入、JSON 模板导入/导出 | 先预览再选择替换/追加，重建 ID/条件/跳转引用，最多 100 道题；AI 单次 3–30 题 |
| 编辑 | 复制、上下移动、删除、撤销/重做 30 步、真实交互预览 | 改动保存后生效，草稿发布权限沿用活动权限 |
| 题型 | 单行、多行、单选、多选、下拉、数字、日期、时间、评分、NPS、排序、矩阵单选、矩阵多选、多项填空、段落说明 | 15 种；矩阵和填空最多 20 子题，选择题最多 50 选项 |
| 规则 | 必填、格式、字数、多选数量、互斥、数值范围和步长 | 前后端共用校验；排序必须为完整不重复的排列 |
| 逻辑 | 复合全部/任一满足、选项与数值比较、嵌套显示、优先级跳转、默认分支及提前结束 | 显示引用前置题，跳转引用前置/本题且目标必须后续；清除隐藏/跳过答案，服务端验证实际路径 |
| 展示 | 3 种配色、标题、说明、成功提示、随机选项、每页题数、手动分页、进度 | 随机仅改变填写展示，原选项值与答案快照保持稳定 |
| 填写 | 错误定位、返回修改、核对提交、失败重试、选填清空 | 成功后当前账号保持一份答卷，保留原并发去重 |
| 续填 | 主动开启浏览器草稿、恢复、关闭即清除、7 天过期、提交后清除 | 按账号/活动/问卷版本隔离；公用设备不应开启；不同设备不互通 |
| 回收 | 现有分页名单、逐份答案、历史快照、姓名/日期/答案筛选 | 原始答卷只向本人及有权限活动管理者开放 |
| 分析 | 选项人数/比例、数值均值、NPS、矩阵分项、排序名次分布 | 按问卷版本分组；分母为此题已作答人数；多选比例可超过 100% |
| 导出 | 按筛选条件导出 UTF-8 BOM CSV | 长表保留题目、类型、版本与复杂答案；公式触发字符转为文本；每次最多 10000 份且读取结果不超过 16 MB |
| 安全 | 服务端权限、匿名最小投影、草稿隔离、无缓存、CSV 公式注入防护、模板限制 | 无新增第三方运行依赖，无新增数据库迁移 |

## 操作路径

1. 登录管理账号，进入“我的账号 → 问卷工作台”，选择活动，点击“编辑与统计”。
2. 选择模板、AI 制作或导入，先预览/试填后替换或追加。通过题目目录逐题编辑，在逻辑区设置显示与跳转，在问卷设置中配置接收时间和主题；最后预览、保存。
3. 先用“预览填写效果”试填，再保存；分享“填写链接”。活动未发布、报名未开放时仍受服务端限制。
4. 在“统计与导出”选择姓名、北京时间日期范围或题目答案筛选，查看图表或导出答卷。清除筛选后需重新查询。
5. CSV 为一题一行；矩阵答案按子题列出。文本、姓名均经过表格公式防护，切勿直接将导出文件用于公共分享。

## 明确未实现

后续增量已实现复合跳转/提前结束、模板制作流程及 AI 生成，详见 [问卷制作说明](QUESTIONNAIRE_STUDIO.md)。以下功能仍有缺口：独立于活动的新问卷资源及匿名调查、附件/图片上传题、图片选项、手写签名、定位、多级联动、动态表格、选项引用、逻辑表达式脚本、回收配额、允许改答/撤回、答卷标记与批量删除、交叉分析/SPSS、答题时长质控、考试评分/题库抽题/监考、多语言、支付/红包、短信、电子签、样本服务、AI 答卷分析、第三方 webhook/CRM、团队邀请等。

当前“问卷工作台”管理已有活动的问卷。活动可从 CMS 或社群发布页创建；没有把模拟活动当作真实社团内容导入生产。

## 小程序兼容

原生小程序 0.2.0 只理解原四种题型。对于包含新题型或跳转规则的问卷，旧 JWT 客户端读取时返回明确提示，要求使用网站活动详情填写，避免出现空白控件。支持本协议的 API 客户端可发送 `X-Questionnaire-Version: 2`。本轮未发布新版小程序；其高级编辑和填写仍需在 littleapp 分支同步。

## 发布与回滚

数据库结构不变。生产部署包含完整数据库备份、隔离恢复验证、源码/媒体备份、服务器独立构建、切换健康检查和回滚脚本。旧代码无法理解新题型；发生上线故障时可恢复上一应用保证站点可用，但必须暂停已采用新题型的问卷，之后恢复兼容代码。历史答卷与备份不删除。
