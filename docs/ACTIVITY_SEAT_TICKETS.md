# 活动座位电子票据

管理员进入活动的“选座工作台”，在“座位电子票据”中批量选择文件。网站支持从本机选择多张图片；小程序支持从微信聊天文件中选择，每次最多选择 100 个文件。文件应按座位命名，例如 `01排01座.jpg`、`01排02座.png`，支持 JPG、JPEG 和 PNG，单张不超过 8 MB。文件名中的排、座必须存在于当前座位图；同一批次中重复的座位会提示并跳过。系统逐张反馈结果，重新上传同一活动和座位会更新票据。

上传的原图按活动与座位保存。选座申请审核通过后，成员在本人选座回执中看到已上传的座位图片，并可在网页保存或在小程序保存到相册。管理员后补图片也会出现在已有的确认回执中；尚未上传的座位显示等待提示。更换、增加或撤销座位后，回执依据当前确认的座位更新。票据图片仅对持有当前确认座位的成员及该活动有权审核选座的管理人员开放；读取响应不进入共享缓存。

存储使用 `activity_seat_tickets` 增量表，票据原图随数据库备份保存。上传时检查文件名、图片格式、大小和解码结果；站点保留原始图片内容。既有申请和座位数据不需要重新提交或批量改写。
