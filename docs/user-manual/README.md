## 更新与生成

主内容源为 `manual_content.py`。修改内容后生成 PDF、HTML 和 Markdown，避免直接修改生成文件导致下次覆盖。

在仓库根目录使用 Codex 依赖加载器返回的 Node/Python，依赖为项目的 `@playwright/test`、Python 的 `reportlab`、`Pillow`、`PyMuPDF`；字体使用 Windows 微软雅黑。

```powershell
& $bundledNode docs/user-manual/render_figures.mjs $chromiumOrEdgePath
& $bundledPython -X utf8 docs/user-manual/build_manual.py
```

`render_figures.mjs` 只做静态源码布局映射，不执行 wx 网络、存储或业务生命周期。它在 `.data/manual-render-source/` 创建文档专用夹具副本，替换旧测试夹具中已停用的进群流程说明；产品模板和原夹具不改动。浅深两套输出和原始映射报告保存在 `.data/manual-a` 至 `manual-d`；文档仅采用选定的浅色图。

`build_manual.py` 将所需图片复制到 `figures/`，输出成品，并把全部 PDF 页面渲染到 `.data/manual-qa/`。生成器检查页数和内容边界；更新后仍需逐页目视核对所有 PNG，并检查 HTML 桌面及手机排版、目录跳转、嵌入图片和外链。验收结果应注明实际执行范围。
