# 产品与范围

网站面向浏览社团信息、寻找参与机会的同学。以紫色文字品牌和校园内容档案为主，无未经授权的学校标识、游戏素材、照片、人员或荣誉。未宣称学校官方门户或校级代表队身份。

已实现：首页、关于、活动列表/筛选/详情、代表队/赛季阵容、荣誉列表/筛选/详情、三类加入页面、招新批次及历史归档、动态、相册分页、联系、隐私、404、错误/加载状态、中文后台。

三类招新共用批次及报名窗口；岗位有职责、要求、投入和安排。站内不收申请数据。仅在发布、未归档、时间开放、未人工关闭、有有效入口时显示报名链接或文字渠道；取消、延期、活动已结束时关闭。截止是左闭右开窗口，时区为 Asia/Shanghai。二维码有文字替代。

没有真实内容的栏目展示空状态；演示需显式导入，荣誉演示保持未核验草稿。每一轮招新、每个赛季独立记录。正文使用受约束富文本；无 HTML/JS 页面生成器。

栏目名称、按钮操作名是产品界面文字；活动、首屏内容、联系人、导航、正文等通过后台维护。首页不展示未经核实的宣传数字。
