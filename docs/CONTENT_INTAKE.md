# 只需负责人提供的内容与授权

内容可分批录入，无需写代码：

- 确认社团全称、简称、对外主办身份、简介、组织结构、发展历程和FAQ。
- 获准使用的社团标识、图片及来源；照片中人物授权范围。不提供则继续文字品牌与空状态。
- 真实活动时间/地点/条件、三类招新岗位与安排、有效外部入口、可公开联系人；每轮单独批次。
- 游戏项目、队名、历史赛季、获准公开昵称/位置；荣誉对应赛事/组别/名次/日期及公开出处，由负责人核验。
- 公共合作联系方式、隐私说明审核、首屏和首页重点。

上线阻塞事项：

- 生产部署授权、目标服务器及运行环境；当前无Docker，需在授权目标完成容器验收。
- 已获准使用的域名、学校名称/标识使用范围、对外主体、部署地区要求，由有权负责人确认；未操作DNS。
- 生产数据库/秘密与持久媒体归属、异机备份目的地、负责人和续费安排。
- SMTP或明确可执行的账号恢复制度；实际SMTP尚未验证。
- 若使用对象存储，提供专属媒体桶配置和费用决定；本地持久媒体方案可先使用。
- 微信真机检查（iOS/Android至少一种），确认外部报名链接实际可达。

账号密码和访问密钥通过安全渠道配置，不能写入Git或本文档。真实活动尚无资料时栏目保持空，不拿演示记录替代正式内容。
