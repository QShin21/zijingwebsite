# 公共浅色默认与深色切换检查点 · 2026-10-13

公共首页与正常网站布局已接入完整浅色默认。首次访问、无偏好和非法偏好都使用浅色，包括系统深色的浏览器。显式切换深色或浅色后，cookie 保存一年；两个根布局直接服务端初始化主题和 metadata，切换组件使用相同初始值，无先绘黑底再改色的初始化。切换只调整显示偏好，保留正在填写的资料和原服务端门禁。

原创金属紫荆图已有独立的明亮石材场景和原深墨场景，分别提供桌面、移动版本。导航、页脚、表单、焦点、禁用、提示和空态使用语义颜色；保留蓝/绿问卷视觉选项，实际问卷定义及版本未改。登录说明去除已关闭的讨论入口描述，普通进群仍为管理员人工拉群。
