# 问卷制作、模板与 AI · 2026-10-11

本次完善问卷制作流程：选择模板、AI 或导入作为起点，预览内容和试填分支，选择替换或追加，进入题目编辑，完成设置后预览并保存。填写与保存继续执行现有活动、角色和版本权限。

## 模板与编辑流程

- 模板库包含 8 个场景：活动报名、满意度反馈、活动偏好、志愿者意向、学习需求、活动复盘、时间安排、参与条件筛选。可按场景筛选及搜索名称、说明、标签。
- 选择模板先显示标题、说明、题型、选项、子题和分支数量；“预览试填”复用真实填写组件。
- “替换”应用题目、标题、说明、主题、分页和完成提示；“追加”只添加题目。两种方式均保留原来的接收状态和报名时间，重建所有题目 ID 与条件/跳转引用。
- 文件或文本导入同样经过校验和预览，再决定应用方式。导出 JSON 保留完整题目、校验、显示与跳转配置；单文件最多 200 KB。
- 制作界面包含题目目录、15 种题型面板、选中题目的设置区，以及“编辑题目 / 问卷设置 / 预览试填”步骤。撤销与重做最多 30 步，连续输入短时间合并为一次编辑。
- 调整顺序会检查关联范围；无效移动被拒绝并给出原因。删除有关联的题目时提示受影响范围，并同时移除对应规则；可撤销恢复。
- 保存仍使用问卷版本，避免覆盖他人刚保存的修改。导入和 AI 结果应用后需要人工保存。

## 条件跳转

每题可设置最多 10 条分支，每个分支可组合最多 10 个条件，支持全部满足（且）和任一满足（或）。条件可用等于/包含、不等于/不包含、已答/未答，以及数字、评分、NPS 题的大于、大于等于、小于、小于等于。

跳转条件只能引用本题及前置的非矩阵作答题；显示条件继续只引用前置题。分支从上到下判断，执行第一条匹配规则。默认分支不设条件，只能放在最后；没有匹配分支则继续下一题。目标可选后续题或结束问卷，禁止向前、自跳、循环和无效目标。若目标题不满足自身显示条件，会继续检查其后题目。

有跳转的题目结束当前填写页。返回修改后重新计算填写路径，隐藏和跳过的答案即时清除。提前结束进入核对步骤，需要明确提交；已经到达的必填题仍需通过验证。服务端独立计算相同路径，过滤伪造的跳过答案，保存实际题目快照。提前结束是答题路径控制；活动报名记录仍遵循现有“提交即记录报名”的规则，不表示新增审核或拒绝参加状态。

旧 JWT 小程序客户端读取含跳转的问卷会收到网站填写提示，支持新版协议的客户端可声明 `X-Questionnaire-Version: 2`。本轮没有上传小程序。

## AI 制作

选用 `DeepSeek-V4.1-Flash`，按 [Paratera 官方 API 使用文档](https://ai.paratera.com/document/llm/quickStart/useApi) 接入 OpenAI 兼容接口。平台公开客户端配置及实际 `/v1/models` 查询确认服务域名为 `llmapi.paratera.com`，且账户可调用该模型。

编辑器提供制作需求、填写对象、3–30 道题和“按需求设计显示与跳转”。生成结果先作为草稿预览，应用后可逐题修改。失败或取消保留当前问卷；不会自动保存或发布。发送内容仅包含本次输入的制作需求，不自动发送已有答卷、账号资料或整个现有问卷。

- 仅有效负责人和活动管理员可生成，服务端检查角色和请求来源。
- 密钥使用服务端 `QUESTIONNAIRE_AI_API_KEY`；可配置 `QUESTIONNAIRE_AI_BASE_URL=https://llmapi.paratera.com/v1`。密钥不进入客户端、模板、日志或仓库，生产配置仅保存在私有环境文件。
- 固定指定模型、固定可信服务域名，禁止跟随重定向；单次超时 80 秒，上游响应最多 400 KB。
- 请求最多 16 KB；题目和逻辑必须经过站点同一套校验。AI 返回不完整、题数不符、无效类型或循环规则时拒绝应用。生成文案如误称匿名填写，会纠正为本站实际登录与答卷访问规则。
- 每账号每小时最多 6 次请求，全站每小时最多 60 次，同时最多 2 次制作。额度保存在现有 `auth_rate_limits`，无新增数据库迁移；失败的上游请求也计入本次额度。

## 验证范围

单元/数据库检查、浏览器场景、真实模型调用和部署证据见 `evidence/questionnaire-studio-20261011.json`。浏览器 AI 交互使用显式本地测试草稿和故障响应；真实上游调用另行记录。CI 不带密钥时只执行权限与交互检查，真实 API 验证需要显式设置 `QUESTIONNAIRE_AI_LIVE_TEST=1`。模拟数据不会导入生产。
