# 后台直接重置用户密码

社长、副社长登录后台后，可直接为用户设置新密码。

1. 打开“用户”，搜索并进入目标用户详情。
2. 点击“更改密码”。
3. 填写新的密码和确认密码，至少 8 位。
4. 点击“保存”。保存成功后，用户使用新密码登录。

该流程无需目标用户的邮箱验证码、旧密码或本人确认。密码沿用 Payload 的加盐哈希存储；重置其他用户的密码会使其原登录会话失效。审计日志记录操作者、目标用户及 `admin-password-reset`，不记录密码内容。

普通用户的自助改密继续使用原验证流程。副社长的角色、任职、账号状态及邮箱管理限制保持原规则。此改动使用既有后台控件与账号字段，无新增数据库迁移。
