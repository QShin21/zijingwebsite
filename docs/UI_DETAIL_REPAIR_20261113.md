# 双端界面细节修复 · 2026-11-13

## 检查范围

以 `main@e61a837` 为基线，将网站公开页、活动与问卷、社群、账号与代表队，以及小程序公开页、社群与选座、代表队、共享组件分为八个范围检查。检查结合源码、合成数据、浏览器布局映射和定向测试；没有使用真实报名资料。

## 修复内容

- 网页问卷管理入口增加间距、换行、当前状态及焦点样式；选座图按主题区分座位状态，满座时键盘仍可进入横向滚动区。
- 社群联系卡片、分区导航与文件选择控件适配浅色和窄屏；无图文章在桌面显示为完整单列。
- 社群详情复用主页各主题的校园插画，简约主题沿用简约背景；社群图标使用适合浅色和深色图案的底板，保留已有自定义图标。
- 代表队登录入口保留原页面及必要的筛选状态，匿名荣誉工作台显示登录入口；长昵称、位置和名次支持换行。
- 小程序修复主题文字、日期卡和选座状态的对比度，扩大返回、筛选和选座点击区域；详情图片加载失败时提供重新加载入口，并补充筛选状态信息。
- 小程序社群页面使用对应的校园插画和图标底板；窄屏错误提示、标题、说明和长文本适配页面宽度。

## 本地验证

- 针对活动、账号、代表队和小程序页面的 11 个测试文件共 221 项通过；小程序包检查通过，包含 29 个页面。
- 四套主题和 320–1440 像素视口的浏览器合成检查覆盖活动选座、问卷入口、社群卡片和部分代表队页面；小程序样式另通过合成布局映射及页面编译检查。
- 三个原有小程序测试文件有 16 项失败、111 项通过，失败名称与改动前 `e61a837` 的测试结果一致。旧夹具仍引用 `session.campus` 的旧接口、已移除页面和不完整的格式化模块桩。
- 微信原生模拟器及真机显示、真实账号登录和生产报名操作留待实际使用核验。

版本号为小程序 `0.5.21`；部署与微信开发版上传结果以本轮发布记录为准。
