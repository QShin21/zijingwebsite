# 论坛移除与小程序只读风采

2026-10-11 用户授权删除双端论坛、发帖、评论回复和点赞；小程序移除图文投稿入口，网页保留用户投稿，并提交 GitHub 和重新部署服务器。

- 网页保留活动与通知、社群风采、用户投稿、本人投稿状态和管理员审核；普通成员投稿仍需审核。
- 双端移除论坛、评论回复、点赞及参加意愿互动；旧页面、REST、后台集合入口和小程序互动桥接返回 404/no-store。
- 小程序删除 compose 页、投稿/审核/隐藏操作；社群风采只查看可见内容及图片、视频链接。源码版本 0.1.2，合法域名检查保持开启。
- 风采创建及审核权限要求服务端 `webShowcaseWrite` 上下文，仅网页 Server Actions 设置；客户端请求正文中的同名字段不能获得该权限。
- 历史论坛、评论、互动数据表和既有迁移保留；无新增迁移，不执行删表或历史数据删除。
- 原主目录未提交的成员审批修改保留在原处，本次在独立工作分支完成并检查。

执行结果与部署恢复路径记录于 docs/evidence/forum-removal-20261011.json；微信审核、正式发布及真实手机验收均单独标注。
