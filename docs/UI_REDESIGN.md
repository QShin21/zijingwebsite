# UI V2 · 竞技编辑部

## 范围与风格

2026-09-20，依据仓库所有者对整体重做及提交推送的授权，在 `redesign/editorial-v2` 实施公开网站改版。保留 Next.js / Payload / PostgreSQL、既有 CMS 模型及服务端权限；不迁移数据库、不改真实内容、不部署生产。

- 深墨色背景、紫荆紫和小面积浅绿；统一字体层级、留白、边线、聚焦状态。
- 重构首页首屏、快捷入口、后台可配模块、三类招新入口和页脚。
- 活动使用日期卡，代表队使用独立色调，荣誉使用档案行，影像使用开放式图文。
- 列表、筛选、详情、赛季阵容、相册分页、报名侧栏、空状态和错误页使用同一设计系统。
- 手机使用原生 details 导航；增强关闭、Escape、外部点击、路由激活和键盘焦点；无 JavaScript 仍可打开导航。
- 无外部字体、图库或动效依赖。Z 图形为本项目原创界面装饰，不能解释为校徽或经授权的官方社团标志。真实后台图片优先；无照片时展示抽象图形，不借用他校、他队照片。

## 内容与兼容边界

原首页字段、模块启停/顺序/去重、精选关系继续生效；已撤下的精选内容回退到可公开内容。首页保留已发布活动供回顾，避免两次活动之间整栏消失。演示标记继续显示。公开查询仍由既有 content.ts 的最小字段及匿名权限控制执行。未新增真实活动、荣誉或人员记录。

旧版 iframe/插件、会员支付和站内申请系统不在本轮范围。未修改后台角色、数据库模式、生产凭据及发布目标。

## 验证与证据

本轮开发容器无法解析外部域名，无法克隆完整私有仓库或安装项目依赖。通过已授权的 GitHub connector 读取代码、提交工作分支，使用仓库 GitHub Actions 执行完整依赖安装、迁移、类型检查、lint、单元/数据库测试、端到端测试和构建。必须以该提交的实际 CI 结果为准。

离线已执行：TypeScript 语法转译；基于实际新组件和样式、模拟 CMS 数据生成 7 种页面，在 Chromium 的 360/390/768/1440 四宽度检查，共 28 组无横向溢出、各有一个 H1。这是布局预览验证，不代表真实 Next.js/React/Payload 端到端运行。预览中的演示内容不进入生产数据库。

新增 tests/presentation.test.ts 验证安全链接与时区日期；新增 tests/e2e/redesign.spec.ts 验证导航、键盘、无脚本、减少动效及六宽度九路由。原发布/权限/外部报名/相册/重定向测试保留。

原 main 的 GitHub Actions 在安装阶段因 @embedded-postgres/linux-x64 未获构建许可而失败。只补充该具体平台依赖的 allowBuilds，保留锁文件、版本与其他供应链规则。

最终 CI 结果与合并状态见 docs/STATUS.md；未通过时不得将该版本称作验收完成。
