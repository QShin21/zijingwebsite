# 自定义活动座位图与本人回执

活动管理员进入该活动的「选座工作台」，打开「自定义座位图」。填写排数和每排列数后点击「应用行列」，再点击方格切换座位与空位；方格可用于安排过道和不规则边界。可以将全部方格设为座位或清空，再保存座位图。网站和小程序均可编辑，排数和列数各支持 1–100，须至少保留一个座位。

方格行号和列号即座位号。例如第 14 排第 50 列对应 `14排50座.png`。活动启用选座前可以先设置布局和上传票据，也可以设置开放时间或立即开放。自主选座、随机安排、管理员锁座、调座和票据均使用该活动当前布局。

新建活动在保存自定义布局前沿用原 381 座图。已有活动继续保留原图：原图已有占用、锁座或票据时，不能直接切换为新图，以保护原有座位编号和位置。自定义图保存后，已被申请、锁定或已有票据的座位不能改成空位或移出范围；清空或缩小前需先处理相关记录。两个管理员同时编辑时，后保存者会收到版本冲突提示，可重新读取后操作。旧版小程序将空位显示为不可选座位。

成员可在活动的「活动报名与本人回执」中查看该活动的选座状态；确认后的电子票据在有图片时显示，可在网站下载，小程序可进入选座详情保存到相册。个人中心的「报名与选座」和小程序「我的选座回执」列出本人各活动最近一次申请。随机安排待审核时显示申请数量，审核通过后显示座位；活动当前不可访问时只显示不可访问提示。

迁移 `20261113_000700_custom_seat_layout` 只增加布局字段、版本和本人记录索引，原活动的空布局继续表示旧座位图。任何活动保存自定义布局后，旧版服务无法正确理解新布局，恢复应采用向前修复或经过核验的数据恢复方案；部署时的回退脚本会检查这一条件。
