# 网页像素校园改版 · 2026-11-12

正式网页接入已确认的像素样板：首页以清华园像素场景、活动入口和真实赛场照片组织内容，内页沿用同一配色、边框与按钮语言。

## 主题与组件

- 清华经典为首次访问默认主题，紫色、暖金与秋日校门；清凉夏夜使用深蓝、薄荷绿和夏日校门；温煦冬日使用暖白、深绿和雪景校门；简约采用系统字体、平面按钮和静态界面。
- 主题保存在原有 zijing_theme Cookie，旧 dark/light 分别映射至经典/冬日。切换直接更新主题，不重挂载表单。
- 网页专属变量在 pixel-campus.css 覆盖，共享 tokens、原生小程序和服务端业务合同保持原样。
- 立体像素按钮具有按下反馈；游戏入口以原创低分辨率几何徽章表现，链接匹配已有社群，未匹配时进入社群目录。
- 主栏按 CMS 配置顺序展示内容，右栏为单图轮播和个人待办/加入路径；收紧尾部间距，小屏改为单列，避免主栏末尾大面积留空。

## 功能保持

保留 CMS 自定义主图、标题、说明、主按钮、焦点活动及全部七类首页区块；保留用户计数、报名状态、封面、完整日程、公告、社群、荣誉与所有业务路径。会员的“我的主场”与桌面主导航并列；移动导航和访客登录入口保留。备案、公安备案及隐私链接保留。

## 动态与素材

封面仅有少量阶梯移动的像素光点；消息与照片每 6.5 秒切换。鼠标停留、键盘焦点进入、区域移出屏幕、页面进入后台、系统减少动态或选择简约时自动停止；手动前后箭头始终可用，不显示暂停键。照片加载失败保留说明、记录链接和切换按钮。

public/pixel-campus/ASSET-PROVENANCE.json 记录素材来源与转换；字体采用 SIL OFL。校门概念画有 AI 标记，CMS 自定义主图不加此标记。三张赛事摄影保留原水印和来源链接；轮播不将赛事示例表述为本社荣誉。存在 CMS 荣誉、风采或文章封面时优先使用原记录及原权限链接。

## 验证边界

已执行主题映射、静态素材白名单、首页组件及导航、首页选择逻辑、社群隐私组件等 36 项测试，并完成类型检查、针对修改文件的 ESLint 和生产构建。浏览器检查桌面与 390/320 像素布局、四主题、输入保持、日程/详情、访客权限边界和照片轮播。完整注册、报名、审批与管理流程未在本轮逐项重跑；对应服务端实现未修改。更新了既有浏览器测试的主题预期，本轮未运行该自动化套件。
