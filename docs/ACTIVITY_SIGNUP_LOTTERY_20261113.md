# 活动报名抽签

站点活动与社群活动的问卷管理页提供“报名抽签”。管理员刷新报名人数、填写中签人数并确认后，系统从当前活动的全部报名记录中等概率抽取，结果立即写入独立记录。报名名单的读取和导出继续遵循既有权限；可以管理问卷但没有名单权限的管理员可以抽签并查看人数。

抽签结果显示在本人报名回执中，状态为“已中签”或“未中签”。抽签后新增的报名显示“未参与本次抽签”，管理员可重新抽签；重新抽签会更新所有人的显示结果，并保留此前每次抽签的候选、结果、操作者和时间。抽签前确认的人数或结果版本变化时，系统要求刷新后重试。

拥有名单导出权限的管理员可在“报名抽签”中下载“抽签结果 CSV”，每份报名一行，包含问卷答案、填写者当前账号邮箱和最新抽签结果；抽签后新增的报名标记为“未参与本次抽签”。“统计与导出”的三种筛选格式在抽签后也包含“抽签结果”列。导出按原有权限、审计和大小限制执行，重新抽签后下载的文件反映新结果。

小程序已具备从服务端回执题目和答案中生成展示条目的能力。服务端在响应中附加“抽签结果”条目，已保存的报名题目、答案和问卷统计保持原样。小程序重新打开报名页面，或点击“重新加载已提交内容”，即可读取新结果。报名人数按报名记录计算，每份记录一次机会。
