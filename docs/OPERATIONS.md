# 内容运营与换届

## 发布活动

登录 `/admin` → 活动 → 新增。填写标题、永久链接标识（小写英文/数字/短横线）、摘要、正文、类型、项目、起止时间、地点、条件。日期选择器为中国标准时间。

填写外部 HTTPS 链接或公共群号；二维码同时填写文字渠道。先打开外部渠道核实，再填写“最近核验渠道时间”。本站不会探测外部表单，也无法阻止外部平台继续收件。设置开始/截止时间及人工关闭。保存草稿 → 预览 → 通知发布负责人检查 → “发布修改”。负责人审核真实性、渠道、图片授权、手机可读性。

已发布页面修改先保存草稿；正式页面保留原内容。发布负责人审核后再发布。紧急撤下使用编辑页操作菜单中的取消发布；归档用于保留历史，并关闭报名。取消/延期单独设置生命周期。撤下后访问详情显示404；取消/结束保留公开档案。版本标签页可查看历史，由发布负责人恢复。恢复后检查当前发布状态和入口时间。

## 招新、赛季、荣誉

每轮新建招新批次，选择普通社员/代表队/骨干类型，填写本轮条件、岗位职责、投入要求、选拔安排、公共联系人和有效渠道。保留旧批次及slug，旧批次勾选归档。

代表队先选择统一游戏项目；新赛季新增“赛季阵容”，关联正确队伍，填写已授权的公开昵称与位置。不要录入学号、私人电话等信息。荣誉关联取得成绩时的队伍和赛季，由发布负责人核实并填写公开来源、勾选核验后发布；私人证明不能上传媒体库。

## 图文、相册与首页

公开媒体只接收PNG/JPEG/WebP，8MB内；为每张图写替代文字与来源/授权备注。公开媒体URL对外可访问，草稿里的图也无保密保障。误传私人图片应立即联系管理员删除并检查存储/CDN，随后按实际影响处理。

活动后新增“回顾”动态并关联活动；新建相册、关联活动、逐张选择授权图片和说明。相册每页12张。无图片保持真实空状态。

管理员进入“站点与首页”维护首屏、按钮、导航、公共联系渠道、模块启用/顺序及推荐。重复模块只展示一次；撤下/未核验推荐不会公开。关于、联系、隐私、加入说明在“固定页面”维护，选择对应key后发布。尚未核实的法律文字不能标记已审核。

## 周期与换届

每周：检查重点活动、过期招新、渠道与二维码、联系人、邮件与备份执行结果。每次活动后补充回顾和相册。每月至少在隔离环境执行恢复演练，查看 `docs/evidence/restore.json` 与当前备份日志。

换届：由管理员建立新账号、按职责分配角色及分部；新负责人真实登录验证；撤销离任账号（必要时删除账号使会话失效）；交接域名/服务器/存储/邮件/仓库归属与续费；检查备份目的地和恢复；更新公共联系方式。凭据在密码管理器或安全渠道交接，不写入本文档。
