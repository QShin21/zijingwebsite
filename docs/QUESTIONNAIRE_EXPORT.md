# 问卷数据导出 · 2026-10-12

在问卷管理页的“统计与导出”中选择导出格式，再点击“导出筛选答卷 CSV”。姓名、提交日期、题目和答案筛选应用于全部格式；CSV 使用 UTF-8 BOM，文件名包含活动名称、格式及北京时间。

## 默认答卷表

每份报名答卷仅有一行，前五列是报名编号、填写者、首次提交时间、最后修改时间和问卷版本。时间转换为北京时间，修改作答后导出保存成功的最新答案。

| 内容 | 导出方式 |
| --- | --- |
| 文本、单选、下拉、数字、评分、NPS、日期、时间 | 每题一列 |
| 多项填空 | 每个填空字段一列 |
| 矩阵单选 | 每个子题一列 |
| 多选、矩阵多选 | 每个选项一列；1 为选中，0 为未选，未显示或无该选项时为空白 |
| 排序 | 每个选项一列，单元格为该选项的名次 |
| 成员名单等信息组 | 记录数一列，每条记录的每个字段各一列，未使用的记录位置留空 |
| 段落说明 | 不作为答案列 |

列名带题号，包含子题、选项、记录序号和字段名。未填写、分支隐藏、未加入当前历史版本的题目及字段留空，不插入“未填写”文本干扰统计。信息组按配置的最大条数预留列，因此五人队伍和六人队伍能在相同列结构内整理。

当前问卷列排在前面，历史答卷快照中的旧题目、旧选项和旧字段仍保留。相同标识的题目改名或更换题型时独立导出，避免混淆历史含义；重复标题或分隔符导致的同名列自动区分。空筛选结果仍导出当前问卷表头。

## 成员明细与按题明细

- 成员明细：每条信息组记录一行，每个字段分列；同时包含所属报名编号、填写者、组内序号、信息组题目及普通题答案，便于筛选姓名、学号和队伍。个人报名等没有信息组记录的答卷在默认答卷表中查看。
- 按题明细：每个答案一行，保留题目标识、题型及完整答案，便于核对或对接已有分析流程。

导出保留文本中的前导零、长数字、中文、逗号、引号和换行。Excel 打开 CSV 时可能自动判断列类型，导入学号、电话等列时应选择文本格式；此提示也显示在导出界面。所有文本单元格继续防止公式注入，真实数值列保留可用于计算的数值。导出沿用原管理权限、筛选限制和不可缓存响应；单份生成文件超过 32 MB 时返回明确提示。没有数据库迁移或生产演示数据导入。
