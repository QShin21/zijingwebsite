# 紫荆电竞社网站｜Codex 开发交接包

本包仅包含任务书与执行指令，不包含网站代码；网站代码由 Codex 在你的项目工作区内实现。

## 使用

把本目录放入 Codex 可访问的项目工作区，保留现有文件。将 `CODEX_START.md` 的正文发给 Codex。它应完整读取总任务书，检查现有环境，然后实际开发。

也可以只提供 `ZIJING_ESPORTS_CODEX_BRIEF.md` 并要求 Codex 按文档立即执行。

## 文件

- `ZIJING_ESPORTS_CODEX_BRIEF.md`：完整产品、架构、权限、安全、测试、部署、执行与交付要求。
- `CODEX_START.md`：可直接粘贴给 Codex 的启动指令。
- `OWNER_CONTENT_CHECKLIST.md`：负责人需要逐步确认的真实资料与上线条件，不要求负责人写代码。

本轮要求完成完整 V1。站内申请审核等未来功能记录在路线图中，不在没有明确需求时一次性开发。

没有生产授权时，Codex 应交付可运行工程和经过验证的部署准备，而不是擅自上线。技术完成、内容准备和正式上线是三个不同状态。
